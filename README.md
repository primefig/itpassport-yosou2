# ITパスポート オリジナル予想問題2 — iPhone対応Webアプリ

これは**問題文の配信を行わない、個人用の解答・採点アプリ**です。問題PDFはユーザーの端末から選び、ブラウザ内のIndexedDBに保存します。GitHub Pagesへ問題PDFや解答例PDFをアップロードしないでください。

## GitHub Pages 公開手順（無料）

1. GitHubにサインインして新しい **Public** リポジトリ（例 `itpassport-yosou2`）を作る。既存の仕事用リポジトリには混ぜない。
2. このZIPを展開し、`index.html`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png`、`.nojekyll` をリポジトリの**一番上の階層**へアップロードしてコミットする（`README.md`は任意）。
3. リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**。
4. 表示された `https://ユーザー名.github.io/リポジトリ名/` をSafariで開く。公開処理はGitHubの反映を待つ。
5. iPhone Safariの共有メニュー→**ホーム画面に追加**→**Webアプリとして開く**→追加。
6. **ホーム画面に追加したアプリから**「問題PDFを登録する」を押し、iPhoneの「ファイル」から `ipcom_yosou_vol2_qs.pdf` を選択する。以降は端末内保存される。
7. 80問を解く。適宜JSONでバックアップし、最後に採点してCSVを保存する。

## 留意事項

- HTML/JSは一般公開され、JavaScriptのソースを読むと正答データにアクセスできます。通常の画面上では提出まで正答非表示ですが、秘密の試験サーバーではありません。
- 問題PDFはサーバー側にアップロードされません。端末内のブラウザ記憶領域だけに保存されます。
- iPhoneのSafariとホーム画面Webアプリの保存領域は異なる場合があります。**必ずホーム画面に追加してから**PDF登録・解答を始めてください。
- 保存領域を削除した場合に備え、JSONバックアップを定期的に保存してください。複数端末の自動同期はありません。
- オフライン機能はHTTPS上で開いたあとキャッシュされます。初回の通信が必要です。
- PDFの `#page=` 指定の動作は端末のPDFビューアに依存します。指定ページに飛ばない場合は手動移動してください。
- 添付の公式問題・解答PDFは出版社に著作権があります。本配布パックには含めていません。
- 採点は80問分の提供資料の解答に基づきます。実際のITパスポート試験のIRT得点とは別物です。
